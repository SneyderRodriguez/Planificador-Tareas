## 📌 Sobre el proyecto

**Thyra** es un proyecto web interactivo diseñado para facilitar la organización y gestión del tiempo. La plataforma permite a los usuarios registrar, visualizar y administrar sus tareas diarias de manera eficiente.

Cada tarea puede ser categorizada por tipo (Estudio, Trabajo, Hogar) y nivel de prioridad (Baja, Media, Alta), lo que permite establecer un flujo de trabajo estructurado con fechas límite claras y un seguimiento detallado de su progreso (Por Hacer, En Progreso, Finalizado).

---

## ✨ Características del proyecto

El sitio cuenta con diferentes secciones orientadas a presentar mi perfil profesional:

* ✏️ **Creación y gestión:** Registro de nuevas tareas con título, descripción, y fechas de inicio y fin.
* 🏷️ **Categorización:** Clasificación rápida de las actividades en los módulos de Estudio, Trabajo u Hogar.
* ⚡ **Priorización visual:** Asignación de niveles de importancia (Baja, Media o Alta) para un mejor enfoque.
* 🔄 **Control de estados:** Capacidad para actualizar y cambiar el estado de progreso de las tareas, así como marcarlas como completadas.
* 💾 **Persistencia de datos:** Uso de localStorage para garantizar que toda la información ingresada se mantenga disponible incluso después de recargar la página.
* 🔍 **Consulta y administración:** Ventanas modales interactivas para consultar los detalles específicos de cada tarea o eliminarlas del registro.
* 📱 **Diseño responsive:** adaptación a diferentes tamaños de pantalla.

## 🖥️ Ejecutar el proyecto localmente

Dado que este proyecto está construido con tecnologías web estáticas (Frontend puro), no requiere la ejecución de un servidor backend con Node.js

### 1. Clonar el repositorio

```bash
git clone https://github.com/SneyderRodriguez/Thyra-Frontend.git
```

### 2. Entrar al proyecto

```bash
cd Planificador-Tareas
```

### 3. Ejecutar

Puedes abrir directamente el archivo:

```text
index.html
```

También puedes utilizar una extensión como **Live Server** en Visual Studio Code para ejecutar el proyecto mediante un servidor local.

## 🚀 Guía de uso rápido

* **Ingresa** los datos: Escribe el "Nombre de la Tarea" en el campo correspondiente.
* **Clasifica:** Selecciona la Categoría (Estudio, Trabajo, Hogar) y la Prioridad.
* **Detalla:** Añade una descripción clara de la actividad a realizar.
* **Programa:** Establece las fechas de inicio y fin en el calendario.
* **Crea:** Haz clic en el botón Submit (Crear) para guardar y visualizar tu tarea en el panel derecho.
